# Phase 2 の結論（2026-11-16）

詳細な数値は [event_study.md](event_study.md)。ここでは要点と、通知設計への反映をまとめる。

## データ

- 開示 624,659件（2019-01〜2026-11、TDnet 全件）→ イベント 228,790件
- 株価が取れたもの 189,909件 → 売買代金1,000万円/日以上 133,266件で集計
- 超過リターン = 銘柄 − TOPIX連動ETF − 同じ規模の対照群（無作為な銘柄・日）の平均

## 補正が必要だった偏り

対照群（イベントと無関係）でも、超小型株は「引け後に通知→翌朝の始値で買う」と20日で平均 −1.0%（t=−9.5）。
小型株がTOPIXに負けやすいことと、寄り付き→引けの値動きの癖による。これを差し引かないと、ほぼ全種別が「売り材料」に見える。

## 限界

- **生存バイアス**: 上場廃止になった銘柄は株価が取れない。TOB・MBOで成立して上場廃止になった銘柄が抜けるため、TOBの数値は実態より小さい。TOB と上場廃止系は数値によらず重要度3に固定した
- 過去分の業績修正は、PDFが消えているためタイトルに「上方」「下方」がある分（約1割）しか方向が分からない。運用中の開示はPDFから判定する
- 同じ日に複数の開示（決算＋自社株買い など）が出た場合、反応を分けられない
- 手数料・スプレッドは考慮していない。超小型株では数十bpの売買コストがかかる

## 通知設計への反映

- 重要度は `data/importance.json`（種別×方向×規模 → 1〜3）に保存し、収集時に適用する
- 小型株・超小型株の重要度3は、直近1年で 1日平均11件（中央値9件、決算集中日は最大76件）
- 内訳: 増資・売出し 726、自社株買い 626、TOB 384、株主優待 330、上場廃止系 201、業務提携 187、上方修正 187、株式分割 18（件／年）
- 運用中は、業績修正をPDFで判定し、営業利益±30%以上なら重要度3にする（この分が上乗せになる）
- 決算集中日の件数を抑える手段（保有・ウォッチ銘柄の優先、1日のまとめ通知）は Phase 3 の通知設定で扱う
